# Decathlon Retail Performance Dashboard | Power BI Project

I’m excited to share my latest Power BI project: **Decathlon Retail Performance Dashboard**.

While working on this project, I focused on understanding retail sales performance and turning raw data into meaningful business insights.

The dashboard provides a clear overview of sales, profitability, product performance, and regional trends.

**Key Highlights:**
- Net Sales YTD: ₹55.26M
- Net Gross Profit YTD: ₹21.72M
- Gross Margin: 39.3%
- Net Units Sold: 46K
- Net Orders: 24K
- Net AOV: ₹2.82K

**Tools & Features Used:**
- Power BI
- DAX Measures
- Data Modeling
- Interactive Slicers
- KPI Cards
- Sales Trend Analysis
- Donut, Bar, and Scatter Charts

This project helped me improve my skills in data visualization, DAX calculations, and business analysis.

I'm learning something new with every project, and I believe consistent practice is the key to becoming a better Data Analyst.

Feedback and suggestions are always welcome!
